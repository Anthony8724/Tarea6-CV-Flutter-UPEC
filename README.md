# Tarea 6 - Evolución de Hoja de Vida

**Universidad Politécnica Estatal del Carchi - Carrera de Computación**

**Docente:** PhD. Samuel Lascano Rivera  
**Integrantes:** Anthony Lopez, Jessica Cuasquen, Carlos Pantoja y Harol Chapi  
**Fecha:** Octubre de 2026

Este repositorio contiene los entregables técnicos de la práctica:

- `codigo_fuente_web/`: hoja de vida responsiva creada con HTML5, CSS3 y JavaScript.
- `cv_flutter_wrapper/`: contenedor móvil Flutter que carga la web desde `assets/web/` mediante `webview_flutter`.
- `Informe_Tarea6_CV.pdf`: informe final de la práctica.
- `Informe_Tarea6_CV.docx`: versión editable del informe.

## Requisitos cumplidos

### Fase 1 - Web CV
- HTML5 semántico con `header`, `main`, `section`, `article` y `footer`.
- Diseño Mobile-First y adaptación a pantallas mayores mediante media queries.
- CSS3 con Flexbox y Grid.
- Interactividad JavaScript: acordeones de proyectos, filtro de habilidades y validación del formulario de contacto.

### Fase 2 - Flutter WebView
- Proyecto denominado `cv_flutter_wrapper`.
- Dependencia `webview_flutter`.
- Carga offline mediante `loadFlutterAsset('assets/web/index.html')`.
- AppBar nativo con botón de recarga y selector de tema claro/oscuro.
- Indicador de progreso de carga.
